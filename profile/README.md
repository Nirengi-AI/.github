# nirengi

**nirengi noktası** — arazide her ölçümün referans aldığı sabit nokta.
haritacılıkta önce nirengi kurulur; her şey ona göre ölçülür.

yapay zekâyla çalışan ürünler kuruyoruz. sektör sektör girip
ölçüyü koyuyoruz.
